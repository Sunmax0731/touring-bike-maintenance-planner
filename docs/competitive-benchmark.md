# 競合ベンチマーク

        ## 比較対象

        - Fuelly: 採用基準は入力負荷、記録粒度、証跡性、ローカル完結性。
- Google Sheets: 採用基準は入力負荷、記録粒度、証跡性、ローカル完結性。
- Notion: 採用基準は入力負荷、記録粒度、証跡性、ローカル完結性。
- 整備記録アプリ: 採用基準は入力負荷、記録粒度、証跡性、ローカル完結性。

        ## 採用する基準

        - 入力負荷が低い。
        - 次アクションが明確。
        - ローカルまたは閉域で検証できる。
        - docs と release evidence から状態を追える。

        ## 差別化

        整備ログ、消耗品、ツーリング前チェックをまとめるWeb管理ツールに絞り、汎用ノートや大型サービスよりも閉域アルファの検証可能性を優先します。
